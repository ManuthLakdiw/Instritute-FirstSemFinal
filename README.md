# 🎓 Institute Management System

A comprehensive desktop application developed to streamline the daily administrative operations of an educational institute. Built using **JavaFX** for the user interface and structured on the **MVC (Model-View-Controller)** architectural pattern, this system ensures a clean, maintainable, and scalable codebase.

## ✨ Key Features
* **Student Management:** Register new students, update details, and manage student records efficiently.
* **Administrative Dashboard:** Interactive and user-friendly dashboard to monitor daily operations at a glance.
* **Database Integration:** Secure and reliable data storage and retrieval using MySQL and JDBC.

## 🛠️ Tech Stack & Architecture
* **Language:** Java
* **Frontend:** JavaFX
* **Database:** MySQL
* **Connectivity:** JDBC (Java Database Connectivity)
* **Architecture:** MVC (Model-View-Controller) / Layered Architecture
* **Tools:** Scene Builder, InteliJ IDE
